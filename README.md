# 共通テスト リスニング練習

大学入学共通テスト（2021〜2026年 本試）とセンター試験（2006〜2019年 本試・追試）の英語リスニングを、年度・大問ごとに練習する Web アプリ。
スマホのホーム画面に追加でき、一度開いたあとはオフラインでも動く。

## 機能

- 共通テスト／センター試験を切り替えて、年度と大問を選んで出題（複数選択、シャッフル可）
- 画面の上に問題、下に解答ボタン（境界をドラッグして高さを変えられる）
- 再生速度 0.5〜2.0 倍（声の高さは変わらない）、5 秒戻る／進む
- 採点（「全部正解の場合のみ得点」の問題に対応）と結果の記録

## 使い方

1. GitHub の Settings → Pages で、このブランチのルートを公開する。
2. 公開された URL をスマホで開き、共有メニューから「ホーム画面に追加」を選ぶ。
3. センター試験はそのまま使える（ネット接続が必要）。
4. 共通テストは、アプリの「素材」で「ファイルをまとめて読み込む」を押し、各年度の問題 PDF と音声 MP3 を選ぶ。
   年度は自動で判定される。判定できなかったファイルは、年度ごとのボタンから選ぶ。

読み込んだ PDF と MP3 は端末の中（IndexedDB）にだけ保存され、どこにも送信されない。

## 素材について

問題冊子の PDF と音声は著作物なので、このリポジトリには入れていない。
リポジトリに入っているのは、正解・配点・ページ番号・大問の開始秒数と、元サイトの URL だけ。

- **共通テスト**：利用者が用意した問題 PDF と音声 MP3 を端末に読み込む。
- **センター試験**：音声と問題画像を [listening.tokyo](https://listening.tokyo) から実行時に直接読み込む（データは [kyotsutest.jp](https://kyotsutest.jp) の各ページから収集）。2019年追試と2020年は元サイトに掲載がないため対象外。

`materials/2025.pdf`、`materials/2025.mp3` のような名前でファイルを置くと、アプリは起動時にそれを自動で取り込む。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` / `app.js` | アプリ本体 |
| `data.js` | 年度ごとの正解・配点・ページ・秒数・URL（`tools/build_data.py` が生成） |
| `tools/center.json` | センター試験の音声 URL・画像 URL・正解 |
| `sw.js` / `manifest.webmanifest` / `icons/` | ホーム画面への追加とオフライン対応 |
| `vendor/` | PDF 表示ライブラリ pdf.js（Apache License 2.0） |

データを直すときは `tools/build_data.py` を編集して `python3 tools/build_data.py` を実行する。
