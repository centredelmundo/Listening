# 共通テスト 英語リスニング練習アプリ 設計書（v0.1）

> **v1 実装時の変更点**
>
> - 素材は kyotsutest.jp・赤本ではなく、利用者が用意した東進の問題 PDF と音声 MP3（2021〜2026 年 本試）を使う。
> - 素材はリポジトリに入れず、アプリが端末内（IndexedDB）に読み込む。問題は pdf.js で PDF のページをそのまま表示する。
> - 音声は 1 年度 1 ファイルなので、大問ごとの開始秒数を `data.js` に持つ。
> - 以下は初版の設計メモで、データソースの節（§1・§2・§6）は現状と異なる。画面と採点の設計（§3〜§5）はそのまま実装している。

## 0. 目的

大学入学共通テスト「英語（リスニング）」の過去問を、**年度・大問を選んで**、**問題を見ながら解答し**、**再生速度を変えて**練習できる Web アプリを作る。

## 1. データソース調査結果（2026-11-11 時点）

| ソース | 収録範囲 | 音声 | 問題（図・選択肢） | 英文スクリプト | 正解 |
|---|---|---|---|---|---|
| listening.tokyo | センター試験 2006〜2019 | あり | あり | あり | あり |
| ┗ 移転先 **kyotsutest.jp** | センター 2006〜2020、**共通テスト 2021〜2023（本試・追試）** | 大問ごとの MP3 | 大問ごとの JPG（問題冊子のスキャン） | あり | あり（ページ内） |
| **akahon.net/kte**（赤本） | 共通テスト **2021〜2026（本試・追試）** | 1 年度 1 本の音声＋問題ごとの開始/終了秒数（`data.js`） | **なし**（書籍に掲載） | なし | **なし** → 添付画像で補う |
| 添付画像 | 2021〜2025 本試 | — | — | — | あり（配点・「全部正解のみ得点」も含む） |

分かったこと:

- listening.tokyo の共通テスト分は **kyotsutest.jp に移転済み**なので、実際の引用元は kyotsutest.jp になる。一部のページは会員（メルマガ登録・無料）のログインが必要な可能性がある。
- 赤本の音声ファイルは、**赤本サイト以外から直接読み込むと 404**（閲覧のみ許可）。さらに赤本サイトには「音声の複製・転載を無断で行うことを禁じる」と明記されている。
- このリポジトリは**公開リポジトリ**。

### 1.1 著作権に関する方針（重要）

音声・問題画像・スクリプトの著作権は、大学入試センター・教学社・各サイトにある。このため、

1. **音声・画像・スクリプトのファイルはリポジトリに入れない。**
2. kyotsutest.jp の素材は、元の URL を**実行時に参照するだけ**にする（ファイルはコピーしない）。
3. 赤本の音声は、赤本サイトから**利用者が自分でダウンロードした MP3** をアプリに読み込ませる（ブラウザ内で再生するだけで、どこにもアップロードしない）。
4. リポジトリに入れるのは、**年度・大問の構成、正解・配点、元 URL、区間の秒数**といった事実情報だけにする。

## 4. 画面設計

### 4.1 画面一覧と遷移

```
[ホーム：選択画面] ──開始──▶ [演習画面] ──終了──▶ [結果画面]
        ▲                                         │
        └──────────── もう一度 / 別の問題 ──────────┘
```

### 4.2 選択画面（機能 1）

```
┌──────────────────────────────────┐
│ 共通テスト リスニング練習           │
├──────────────────────────────────┤
│ 年度  [2025本][2024本][2023本][2023追]… │  ← 複数選択可
│ 大問  [第1問A][第1問B][第2問][第3問]   │  ← 複数選択可
│       [第4問A][第4問B][第5問][第6問]   │
│ 速度  ( 0.75  0.9  [1.0]  1.1  1.25 ) │
│ ☐ 問題の順番をシャッフル                │
│                                      │
│ 選択中: 3年度 × 2大問 = 6セット         │
│            [ 開始 ]                   │
└──────────────────────────────────┘
```

- 「年度×大問」の組み合わせを 1 セットとして、順番に出題する。
- 赤本音源の年度で MP3 が未読み込みなら、ここで「MP3 を読み込む」ボタンを出す。

### 4.3 演習画面（機能 2・3）

```
┌──────────────────────────────────┐
│ 2023本試 第1問A  問1〜4      1/6   ✕ │ ← ヘッダ
├──────────────────────────────────┤
│                                      │
│   【問題エリア】（上部・スクロール可）  │
│    ・問題画像（kyotsutest）           │
│      ピンチ / ボタンで拡大            │
│    ・画像がない年度は                 │
│      「問1 ①〜④から選べ」等の文字表示 │
│                                      │
├──────────────────────────────────┤
│ ▶ ⏪3秒 ━━━━●━━━━ 0:42/1:58  [1.0x]│ ← 再生バー（固定）
├──────────────────────────────────┤
│ 【解答エリア】（下部・固定）           │
│  問1  (①)(②)(③)(④)                  │
│  問2  (①)(②)(③)(④)                  │
│  問3  (①)(②)(③)(④)                  │
│  問4  (①)(②)(③)(④)                  │
│                  [ 採点して次へ ]     │
└──────────────────────────────────┘
```

- **上下 2 分割**: 上の問題エリアだけがスクロールする。下の解答エリアと再生バーは常に画面下部に固定する。画面の高さのうち、問題エリア約 55%、解答エリア約 45% を目安にし、境界線をドラッグして比率を変えられるようにする。
- **解答ボタン**: 選択肢の数（4 または 6）はデータから決める。第4問A 問22〜25 と第5問 問28〜31 は ①〜⑥。
- 問題数が多い大問（第4問A は 8 問）は、解答エリアの中だけスクロールさせる。
- PC では横幅が広くても上下レイアウトを維持する（要望どおり）。

### 4.4 速度変更（機能 3）

- `HTMLAudioElement.playbackRate` を使う。選択肢は **0.5 / 0.75 / 0.9 / 1.0 / 1.1 / 1.25 / 1.5 / 2.0**。
- `preservesPitch = true` にして、速度を変えても声の高さが変わらないようにする。
- 再生中でも変更でき、選んだ速度は次の問題にも引き継ぐ（ブラウザに保存）。
- 補助機能として「3 秒戻る / 3 秒進む」と、区間の頭から再生し直すボタンを付ける。

### 4.5 結果画面

- 大問ごとに、得点 / 満点、正答率、各問の ○× と「自分の答え → 正解」を表示する。
- 「全部正解のみ得点」のグループ（第4問A 問18〜21、第5問 28-29・30-31）は、採点ルールどおりに計算する。
- kyotsutest に英文スクリプトがある年度は、元ページへのリンク「スクリプトを見る」を出す。
- 「間違えた大問だけもう一度」ボタンを付ける。
- 解答履歴は `localStorage` に保存し、ホームに「前回の結果」を表示する。

```

│   ├─ app.js        画面遷移・状態管理
```

### 5.3 採点ロジック

```
大問の得点 =
    Σ(グループに属さない問の、正解した問の配点)
  + Σ(グループのうち、全問正解したグループの配点)
```

## 6. 音声再生の仕組み

- **kyotsutest（2021〜2023）**: 大問ごとの MP3 を `<audio src>` で直接読み込む。区間 = ファイル全体。
- **赤本（2024〜）**: 利用者が赤本サイトの「一括ダウンロード」で入手した ZIP を解凍し、その MP3 をファイル選択で読み込む。`URL.createObjectURL()` でブラウザ内だけで再生し、`timeupdate` で `end` 秒に達したら止める。区間ごとにファイルが分かれている場合は、ファイル名から対応を付ける（ZIP の中身は実装時に確認する）。
- 読み込んだ MP3 は IndexedDB に保存して、毎回読み込み直さなくて済むようにする（端末内だけ）。

## 7. 実装の順番

1. 添付画像から 2021〜2025 本試の正解・配点を `data/*.json` に書き起こす。kyotsutest から 2021〜2023 追試の正解を集める。
2. kyotsutest の 2021〜2023 の各大問ページから、音声 URL・画像 URL・スクリプト URL を集める（会員限定ページがあれば報告する）。
3. 選択画面 → 演習画面 → 結果画面を実装する（まず kyotsutest 年度で動かす）。
4. 速度変更・3 秒戻る・区間リピートを付ける。
5. ローカル MP3 読み込み（赤本年度）に対応する。
6. Playwright でスマホ幅・PC 幅の表示を確認する。

## 8. 将来の拡張候補

- 自分で撮った問題ページの写真を、年度・大問に紐付けて上部に表示する（端末内保存）。
- 「1 回読み」練習（共通テストは第1・2問が 2 回読み、第3問以降は 1 回読み）。
- 間違えた問題だけを出題する復習モード。
- センター試験（2006〜2020）への対応（kyotsutest にある）。
